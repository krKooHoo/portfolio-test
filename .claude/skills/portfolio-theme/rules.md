# /portfolio-theme 규칙 — 무엇을 어떻게 뽑나

스크린샷 한 장에서 "느낌"을 옮기는 일은 사람마다 달라지기 쉽습니다. 그래서 **무엇을 볼지(§2)·어떤 값만 쓸지(§1)·어디까지 맞출지(§3)**를 고정해 두었습니다.
같은 화면이면 누가 해도 비슷한 테마가 나오고, 어떤 테마를 써도 세 페이지(포트폴리오 문서·발표 덱·상세 문서)가 깨지지 않게 하기 위함입니다.

## 1. 손잡이 표 — `theme/theme.css`에 쓰는 것은 이것뿐

렌더러 CSS는 이 손잡이(`--t-*`)만 읽습니다. 파일에는 영문 글꼴 `@import`와 `:root { --t-… }` 한 블록만 둡니다(다른 선택자·규칙 금지 — 발표 덱은 장면마다 글자 크기를 재서 배치하므로 크기·간격을 바꾸는 규칙이 들어가면 배치 점검이 깨집니다).

| 손잡이 | 뜻 | 보이는 곳 | 값 | 비었을 때 |
|---|---|---|---|---|
| `--t-scheme` | 화면 모드 | 스크롤바·입력 칸 기본색 | `dark` · `light` | `dark` |
| `--t-bg` | 바탕 | 페이지·장면 바탕 | `#RRGGBB` | `#0A0A0D` |
| `--t-surface` | 카드·판 | 프로젝트 판·기능 목록·표·코드 밖 판·덱 카드 | `#RRGGBB` | `#131318` |
| `--t-ink` | 제목 글자 | 제목·덱 본문 | `#RRGGBB` | `#F4F4F6` |
| `--t-body` | 본문 글자 | 포트폴리오 문서·상세 문서 본문 | `#RRGGBB` | `#BDBDC7` |
| `--t-muted` | 보조 글자 | 날짜·캡션·라벨 | `#RRGGBB` | `#9A9AA6` |
| `--t-line` | 얇은 선 | 구분선·카드 테두리 | `#RRGGBB` | `#24242C` |
| `--t-line-2` | 진한 선 | 알약 버튼·태그 테두리 | `#RRGGBB` | `#3D3D48` |
| `--t-accent` | 강조색 | 버튼 칠·링크·라벨·표 머리 밑줄 | `#RRGGBB` | profile.md 강조색 |
| `--t-accent-2` | 그러데이션 둘째 색 | 라벨 그러데이션 끝·광채 | `#RRGGBB` | 강조색을 보랏빛 쪽으로 50° |
| `--t-accent-3` | 광채 셋째 색 | 번호 배지 끝·장 표지 광채 | `#RRGGBB` | 같은 쪽으로 95° |
| `--t-radius` | 큰 모서리 | 카드·판(작은 모서리는 이 값의 비율) | `0px`~`32px` | `20px` |
| `--t-pill` | 버튼 모서리 | 버튼·태그·칩·덱 아래 띠 버튼 | `0px`~`999px` | `999px`(알약) |
| `--t-shadow` | 그림자 색 | 떠 있는 카드·창·덱 표지 그림 | 색 하나 | `rgb(0 0 0 / .8)` |
| `--t-display` | 영문 라벨 글꼴 | PORTFOLIO·CHAPTER 같은 눈썹 글자, 목차 머리, 머리 뒤 큰 영문 이름 | §2-8 표의 이름 | `'Montserrat'` |
| `--t-grad` | 라벨 글자 칠 | 눈썹 글자·영문 이름·FEATURE 번호 | 그러데이션 | 강조색 → 둘째 색 |
| `--t-badge` | 번호 배지 칠 | 기능 번호·목차 번호·자리 표시 | 그러데이션 또는 `var(--accent-fill)` | 강조 → 둘째 → 셋째 광채 |
| `--t-glow` | 배경 광채 세기 | 포트폴리오 문서 머리·연락처, 덱 표지·목차·장 표지·맺음 | `0`~`1` | `1` |
| `--t-mark` | 큰 영문 이름 | 포트폴리오 문서 머리 뒤 장식 글자 | `0`~`1` | `1` |
| `--t-faint` | 흐린 글자(선택) | 상세 문서 각주·덱 전체 보기 장면 id | `#RRGGBB` | 보조 글자 85% + 바탕 |
| `--t-code-bg` | 코드 판(선택) | 코드 블록 | **어두운** `#RRGGBB` | `#111116` |
| `--t-diagram` | 다이어그램 판(선택) | 발표 덱·상세 문서의 mermaid 그림 판 | **밝은** `#RRGGBB` | `#F4F5FA`(차가운 회청색) |

템플릿은 [theme-template.css](theme-template.css). 표에 없는 손잡이는 렌더러가 읽지 않으므로 쓰지 않습니다(`check-theme.py`가 막음).

## 2. 뽑는 순서 — 스크린샷 → 손잡이

스크린샷에서 **가장 넓은 면적부터** 봅니다. 그림이 **파일로 있으면**(경로가 주어졌거나 브라우저 도구로 찍은 경우) 눈대중 대신 실제 픽셀을 읽습니다 — 같은 그림이면 누가 해도 같은 값이 나오게:

```bash
python .claude/skills/portfolio-theme/sample-colors.py <그림.png>                    # 넓은 면의 색(바탕·카드·선) — 면적 % 순
python .claude/skills/portfolio-theme/sample-colors.py <그림.png> --at 120,480 300,90   # 좁은 곳(글자 획 가운데·버튼 칠·모서리)
```

대화에 붙여 넣은 그림처럼 파일이 없으면 눈대중으로 "가장 가까운 #RRGGBB"를 고릅니다. 어느 쪽이든 §3에서 대비를 맞추며 밝기만 다듬습니다.

1. **모드** — 본문 영역 바탕이 어두우면 `dark`, 밝으면 `light`. 첫 화면(히어로)만 어둡고 아래가 밝은 사이트는 **아래 본문 쪽**을 따릅니다(포트폴리오는 대부분 본문을 읽는 페이지).
2. **바탕 `--t-bg`** — 가장 넓은 면의 색. 순수 `#000000`·`#FFFFFF`도 그대로 씁니다.
3. **카드 `--t-surface`** — 카드·패널·입력 칸의 색. 화면에 카드가 없으면 바탕에서 한 단: 어두운 바탕은 바탕보다 조금 밝게(바탕 + 글자색 4~6%), 밝은 바탕은 `#FFFFFF`(바탕이 이미 흰색이면 바탕보다 2~3% 어둡게).
4. **글자 세 단** — 가장 큰 제목 색 → `--t-ink`, 문단 글자 → `--t-body`, 날짜·캡션·작은 라벨 → `--t-muted`. 화면에서 두 단만 보이면 본문을 제목과 보조의 중간으로 정합니다.
5. **선 두 단** — 카드 테두리·구분선 → `--t-line`, 외곽선 버튼·태그 테두리 → `--t-line-2`(없으면 `--t-line`보다 한 단 진하게).
6. **강조색** — 버튼 칠·링크·하이라이트에 쓰인 가장 채도 높은 색 → `--t-accent`.
   - 그러데이션(글자·버튼·카드)이 보이면 시작 색 = `--t-accent`, 끝 색 = `--t-accent-2`, 세 번째 색이 있으면 `--t-accent-3`.
   - 강조가 한 색뿐이면 `--t-accent-2`·`--t-accent-3`을 **`--t-accent`와 같은 값**으로 둡니다. 지우면 페이지가 짝 색(보랏빛 쪽으로 돌린 색)을 만들어 목차·장 표지의 선 끝 점, 덱 진행 막대, 자기소개 막대 끝에 다른 색이 보입니다.
   - 강조색이 흑백(채도 없음)뿐인 화면이면 `--t-accent` 줄을 지워 profile.md 강조색을 씁니다.
7. **모양** — 카드 모서리를 카드 높이와 비교해 가까운 값: 각짐 `0px` · 살짝 `8px` · 둥근 `14px`~`20px` · 아주 둥근 `24px`~`28px`.
   파일이 있으면 카드 모서리에서 바탕색이 끝나는 곳까지의 픽셀 수를 `--at`으로 재면 정확합니다.
   버튼 양 끝이 반원이면 `--t-pill: 999px`, 아니면 버튼 모서리 값(보통 `4px`~`10px`).
   그림자: 어두운 바탕은 `rgb(0 0 0 / .8)`. 밝은 바탕은 카드 아래에 그림자가 **조금이라도 보이면** `rgb(20 22 30 / .16)`, **전혀 없으면**(테두리만) `rgb(20 22 30 / .08)`.
8. **영문 라벨 글꼴** — **가장 큰 영문 제목**의 인상으로 아래에서 하나. 작은 라벨(눈썹 글자)과 큰 제목의 글꼴이 다른 화면이면 **큰 제목이 이깁니다** —
   이 페이지들에서 한글 제목은 늘 Pretendard라, 레퍼런스의 개성은 이 영문 글꼴(머리 뒤 큰 영문 이름·목차 머리 CONTENTS·장 번호)에서만 드러나기 때문입니다.
   그래서 세리프를 고르면 눈썹 글자도 세리프가 되고, 덱 표지의 작은 항목 이름(장르·저장소 등)은 Pretendard 그대로 남습니다(정상). 숫자는 페이지가 늘 같은 높이 숫자로 맞춥니다. 글꼴 이름을 알아보더라도 **목록 밖 글꼴은 쓰지 않습니다**(주소·버전·700/800 굵기를 확인해 둔 것만 — 굵기가 없으면 라벨이 가짜 굵게로 번져 보임).

   | 인상 | 글꼴(`--t-display`) | `@fontsource` 패키지 | 폭 |
   |---|---|---|---|
   | 굵고 둥근 기하학(게임·테크 회사풍) | Montserrat(기본, @import 없음) · Poppins · Outfit | — · `poppins` · `outfit` | 넓음 · 넓음 · 보통 |
   | 중립·깔끔(제품·SaaS) | Inter · Manrope · Plus Jakarta Sans | `inter` · `manrope` · `plus-jakarta-sans` | 보통 |
   | 각지고 단단한 테크 | Sora · Archivo | `sora` · `archivo` | 넓음 · 보통 |
   | 좁고 높은 대문자(스포츠·포스터) | Barlow Condensed | `barlow-condensed` | 좁음 |
   | 세리프(잡지·에디토리얼) | Playfair Display | `playfair-display` | 보통 |
   | 둥글고 친근 | Nunito | `nunito` | 보통 |
   | 고정폭(터미널·개발자) | JetBrains Mono | `jetbrains-mono` | 넓음 |
   | 영문 라벨을 따로 두지 않음(한글 위주 화면) | Pretendard(@import 없음) | — | — |

   주소는 `https://cdn.jsdelivr.net/npm/@fontsource/<패키지>@5.3.0/latin-700.css`와 `latin-800.css` 두 줄(버전 고정). 한글은 늘 Pretendard입니다(§4).
9. **효과**
   - 라벨 글자 `--t-grad`: 화면의 제목·라벨에 그러데이션 글자가 있으면 2색(`linear-gradient(90deg, var(--accent-ink), var(--accent-2-ink))`), 없으면 단색(`linear-gradient(var(--accent-ink), var(--accent-ink))`).
   - 번호 배지 `--t-badge`: 그러데이션 칠 카드·버튼이 있으면 광채(템플릿 주석의 3색), 없으면 `var(--accent-fill)`.
   - 배경 광채 `--t-glow`: 바탕에 번진 빛이 크게 보이면 `1`, 은은하면 `.5`, 평평하면 `0`.
   - 큰 영문 이름 `--t-mark`: 배경에 크게 깔린 장식 글자(흐린 대문자)가 있으면 `1`, 없으면 `0`. 글자는 **수강생의 영문 이름**입니다(레퍼런스의 문구가 아님).

10. **다이어그램 판 `--t-diagram`** — 어두운 바탕이면 줄을 지웁니다(기본 밝은 회청색 판). 밝은 바탕이면 **카드 색과 같게** 둡니다(크림·베이지처럼 따뜻한 바탕 위에서 차가운 회청색 판이 튀지 않게). 판은 늘 밝아야 합니다(§4).

수강생의 덧붙인 요청(`$ARGUMENTS` 또는 대화)이 있으면 위 결과보다 그 요청을 따릅니다(예: "강조색은 내 색 유지" → `--t-accent`·`-2`·`-3` 줄 지움).

## 3. 대비 규칙 — `check-theme.py`가 확인

| 짝 | 기준 | 못 미치면 |
|---|---|---|
| 제목 글자 / 바탕 · 카드 | 12 · 10 이상 | 제목 글자를 바탕 반대쪽으로(어두운 바탕이면 더 밝게) |
| 본문 글자 / 바탕 · 카드 | 7 이상 | 본문 글자를 바탕 반대쪽으로 |
| 보조 글자 / 바탕 · 카드 | 4.5 이상 | 보조 글자를 바탕 반대쪽으로 |
| 라벨 칩 글자 / 칩(제목 글자 22% + 바탕) | 4.5 이상 | 제목 글자를 바탕 반대쪽으로 |
| 흐린 글자 · 구분선 · 알약 테두리 · 카드 구분 | 3 · 1.15 · 1.5 · 1.04(참고) | 참고만 — 너무 안 보이면 한 단 진하게 |
| 코드 판(쓸 때만) | 코드 글자 `#E6E8F5`와 7 이상 | 어둡게(코드 강조색이 어두운 판 기준) |
| 다이어그램 판(쓸 때만) | 다이어그램 글자 `#333333`과 7 이상 | 밝게(학생 문서의 mermaid 테마가 밝은 판 기준) |

- 고칠 때는 **색상(색의 종류)은 그대로 두고 밝기만** 바탕 반대쪽으로 조금씩 옮깁니다(레퍼런스의 느낌을 지키면서 읽히게). 바탕·카드 색은 되도록 건드리지 않습니다.
- 강조색 대비는 페이지가 바탕에 맞춰 자동으로 맞춥니다(글자용 강조색은 바탕 7:1 이상, 흰 글자를 올리는 칠은 4.5:1 이상, `common.js` PF.applyTheme). 그래서 강조색은 레퍼런스 색 그대로 씁니다.
- `--t-scheme`은 바탕 밝기와 맞아야 합니다(어긋나면 [고칠 것]).

## 4. 바꾸지 않는 것 — 테마가 닿지 않게 고정해 둔 곳

| 고정 | 이유 |
|---|---|
| 배치·글자 크기·간격 | 발표 덱은 글자를 재서 장면을 나누고 줄이므로, 테마가 크기를 바꾸면 잘림·넘침이 생깁니다 |
| 한글 글꼴 Pretendard | 본문 가독성, 세 페이지의 글자 폭(덱 측정)이 같게 |
| 코드 블록은 어두운 판 + github-dark | 코드 강조 색이 어두운 판 기준 |
| 다이어그램은 밝은 판 | 수강생 문서의 `%%{init}%%` 밝은 mermaid 테마가 어두운 바탕에서 안 읽힘 |
| 인쇄(포트폴리오 문서 = 제출 PDF · 상세 문서)는 흰 종이 | 제출 PDF는 흑백 인쇄·잉크·가독성 기준. 강조색만 테마를 따름. 발표 덱 PDF는 화면 그대로 |
| 빨간·노란 미리보기 띠 | 점검 표시라 눈에 띄어야 함 |
| 레퍼런스의 로고·회사/서비스 이름·문구·그림·아이콘·일러스트 | **옮기지 않습니다.** 포트폴리오는 수강생 자신의 것이고, 남의 브랜드처럼 보이는 페이지가 되면 안 됩니다. 색·모양·글꼴 인상만 가져옵니다 |

배치까지 새로 그리고 싶다는 요청이면 `/portfolio-custom`(직접 생성 모드, 수강생이 직접 입력)을 안내합니다.

## 5. 이어서 고치는 말 → 손잡이

| 요청 | 바꿀 손잡이 |
|---|---|
| 버튼을 덜 둥글게 / 네모로 | `--t-pill: 8px` / `0px` |
| 카드를 더 각지게 / 더 둥글게 | `--t-radius` 낮게 / 높게 |
