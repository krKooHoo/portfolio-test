# 기준 ⑤ 직접 생성 모드 — Claude가 HTML을 처음부터 만들 때

> 원본: 「유니티 개발자 취업·기술 문서 작성 가이드 v2」 **Part 6 트랙 B · 만능 틀 ③④**
> (https://koohoo-dev.github.io/portfolio-guide/guide.html#6)

이 템플릿의 **기본은 고정 렌더러**(`index.html`·`project.html`)입니다. 디자인이 깨지지 않고,
여러분은 **내용 검증**에만 집중하면 됩니다.

그래도 "내 포트폴리오만의 디자인"을 원한다면, **직접 생성 모드**로 Claude에게 페이지를 새로 그리게 할 수 있습니다.
같은 소스(`src/`)와 같은 데이터(`data/`)를 쓰므로 **내용은 그대로, 겉모습만** 달라집니다.

| | 고정 렌더러 (기본) | 직접 생성 모드 (선택) |
|---|---|---|
| 실행 | `/portfolio-build` | `/portfolio-custom [디자인 요청]` — **직접 입력할 때만** 실행 |
| 결과 | `index.html`, `project.html` | `custom/index.html` (단일 HTML) |
| 디자인 | 중립 + 강조색 1개 | 자유 (요청한 대로) |
| 안정성 | 높음 (매번 같은 결과) | 실행마다 달라짐 — **매번 직접 확인** 필요 |
| 기술 | 순수 HTML/CSS/JS | React CDN + Tailwind CDN 단일 파일 |

> 직접 생성 결과를 메인으로 쓰고 싶다면, 충분히 확인한 뒤 `custom/index.html`의 링크를
> 이력서에 넣으면 됩니다. 고정 렌더러는 그대로 두어 **비교·백업용**으로 남겨 두세요.

## Claude가 따르는 생성 규칙

1. **설치·빌드 없이** 브라우저에서 열리는 **단일 HTML 파일**. React는 CDN(버전 고정), 스타일은 Tailwind CDN.
2. **내용은 `data/portfolio.json`·`data/projects/*.json`에서만** 가져온다. 새 사실을 지어내지 않는다.
3. 기술 문서 전문은 복사하지 않고 **기존 `project.html?p=<폴더명>`으로 링크**한다.
4. 이미지는 **상대경로**(`../src/<폴더>/images/...`)로. 절대경로(`/src/...`) 금지 — Pages에서 깨짐.
5. 취업용답게 **깔끔하고 절제되게**, 템플릿 같지 않게. 여백·타이포그래피 중심, **3색 이내**, **반응형**.
6. 레이아웃 패턴은 기준 ④의 13종 안에서 고른다.

## 수강생이 직접 쓸 때 참고하는 만능 틀

**생성** — `/portfolio-custom` 뒤에 붙일 디자인 요청 예시:

```text
다크 톤에 강조색은 내 profile.md 색 그대로. 첫 화면은 이름과 한 줄 소개만 크게,
스크롤하면 프로젝트 카드가 하나씩 나타나게. 카드에는 커버 이미지를 크게.
```

**다듬기** — 결과를 본 뒤 이어서 말하기 (실무의 핵심은 이 반복입니다):

```text
방금 만든 페이지에서 [이 부분]을 [이렇게] 바꿔줘.
나머지는 그대로 유지하고 이 부분만 수정해줘.
```

> 한 번에 완성하려 하지 말고, 초안 → 다듬기를 반복하세요. 그리고 **결과물을 이해하지 못한 채 쓰지 마세요.**
